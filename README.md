## About Me

안녕하세요, **AI 모델을 실제 서비스로 연결하는 백엔드 개발자 임정원**입니다.

청각장애인을 위한 수어 뉴스 서비스(MkTone), 한국어·한국수어 번역 서비스(Signmate), 시각장애인을 위한 배리어프리 키오스크처럼
**기술이 닿지 않던 사람들의 문제를 푸는 프로젝트**에 꾸준히 참여해 왔습니다.
FastAPI와 PostgreSQL·pgvector 기반의 백엔드, RAG 파이프라인, 수어 데이터 처리와 비전 모델 연동이 주로 맡아 온 영역입니다.

매일경제 × Anthropic AI 해커톤 대상, ASCII-THON 1등, CAU 다학제 캡스톤 총장상 등
**팀 프로젝트에서 결과를 끝까지 만들어 낸 경험**이 가장 큰 자산이라고 생각합니다.
새로운 기술과 환경을 빠르게 익히고, "동작하는 프로그램"에서 멈추지 않고 **설계를 설명할 수 있는 코드**를 만드는 것이 목표입니다.

- **중앙대학교 소프트웨어학부** 재학
- **SKT FLY AI Challenger 8기** 수료
- 관심 분야: Backend · RAG / Vector Search · Computer Vision · AIoT
